How does a weight get written into a PCM cell?

In a PCM array the weights are conductances, and a cell is pushed to one with heat pulses and then checked. The idea is the same as for ReRAM, but the physics changes the rules: every pulse has the same polarity, SET crystallizes a little at a time, and RESET cannot step down. Follow one weight through the six steps below.

    Check yourself

    Why does a PCM write loop erase first, and why does an overshoot cost so much?

    SET pulses only shrink the amorphous dome, and RESET rebuilds the whole dome in one go, so there is no small step downwards. If a pulse lands above the tolerance band, the only fix is a RESET and a new climb. That is why the controller picks gentle pulses as it gets close. Set a large σ in step 5 and press “Try a different cell” to see restarts.

    The levels are evenly spaced in conductance. Why are they not evenly spaced in dome size?

    G = Gmax·(Gmin/Gmax)a, so conductance falls exponentially as the dome grows. Equal steps of G near Gmax need very small changes of a, and near Gmin the same G step needs a much larger one. Compare the “dome a” values in step 3 for level 1 and the top level.

    Why does open loop (no read-back) land so far from the aim on some cells?

    The same pulse shrinks the dome by a different factor on every cell, and the factor compounds over many pulses. Verify reads cancel that out by stopping each cell when it is close enough. Switch to “Open loop” in step 5 and press “Try a different cell” a few times.

    The verify read says the cell is exactly on target. A year later it reads lower. Did the write fail?

    No. The write was correct, but the amorphous glass relaxes and G falls as a power law of the time since the write. Drag “Time since write” in step 6. The verify read cannot see this, because it happens right after the pulse, so drift has to be handled separately (Step 1, section 4).

    A weight is written once and used a million times. Which cost matters more, the write or the read?

    If the weights are reused, the write cost (a RESET plus a climb of SET pulses and reads) is shared across all of those multiplies, while every multiply pays for its own read-out. The write is expensive in PCM, so it only pays off when the weights are reused many times, as in inference.
