AgilA32 Simulator

The chip's own Verilog (RV32I CPU and two-state-machine PIO), compiled to WebAssembly and running in this page. Chip clock 24 MHz; the simulation itself runs slower than real time.

AgilA32 on GitHub: github.com/alexandercoabad/AgilA32_PIO
  • RV32I CPU
  • 2 PIO state machines
  • 24 MHz
  • IHP CMOS5L
  • Tiny Tapeout 8x4 tiles

Built for the Jane Street protocol-emulator ASIC competition: a small RISC-V core plus RP2040-style PIO that firmware turns into UART, SPI, I2C and other protocols after fabrication.

Quick start

  1. The chip is already running PILIPINAS AGILA32: watch the 7-segment display and the LEDs.
  2. This program ignores the input switches. To see them work, run the C example switches: the LEDs copy ui0-ui7 as you click them.
  3. Pick another scenario and press Load and run: the C examples and the PIO tests are in the list.

Board

Inputs ui_in[7:0] (click a switch)
Outputs uo_out[7:0]
7-segment display (common cathode): uo0-uo6 = segments a-g, uo7 = dp
Bidirectional uio[7:0] (outlined = chip drives the pin)

Block diagram (live)

        
        
Redrawn from the block diagram in the project documentation. Highlighted blocks are in use: the memory block that holds the current instruction, the target of a load or store (worked out from the instruction and its base register), the QSPI engine while a chip-select is low, and each PIO state machine when its program counter moves. The little circles are the ten PIO pins; a ring means the PIO drives that pin.
