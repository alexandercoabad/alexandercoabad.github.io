ReRAM Crossbar Simulator

Weights are stored as conductances in a resistive-RAM crossbar. Input voltages on the word lines produce bit-line currents that already equal the matrix product, Iⱼ = Σᵢ Vᵢ·Gᵢⱼ, so the multiply and the sum both happen inside the array.

This is a generic, textbook model of analog ReRAM compute-in-memory: a passive crossbar with differential conductance pairs, a quantized DAC and ADC, Gaussian device variation and wire IR drop. It is meant for learning and quick experiments, not as a novel architecture or a model of any specific chip.

Array size

Each output uses two bit lines (G⁺ and G⁻), so signed weights map to non-negative conductances.

Each cell current is Vᵢ·Gᵢⱼ (Ohm). The bit line adds them (Kirchhoff). The two bit lines of a pair are subtracted, then scaled by Vread·(Gmax−Gmin) to recover the weighted sum.

Efficiency versus digital multiply-accumulate

A conventional processor fetches every weight from memory and performs the M×N multiply-adds one batch at a time. The crossbar keeps the weights where they are and finishes all of them in a single read.
