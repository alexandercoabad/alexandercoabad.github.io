ReRAM Crossbar Simulator

Weights are stored as conductances in a resistive-RAM crossbar. Input voltages on the word lines produce bit-line currents that already equal the matrix product, Iⱼ = Σᵢ Vᵢ·Gᵢⱼ, so the multiply and the sum both happen inside the array.

This is a generic, textbook model of analog ReRAM compute-in-memory: a passive crossbar with differential conductance pairs, a quantized DAC and ADC, Gaussian device variation, wire IR drop and a pulse-and-verify model of how the weights are written. It is meant for learning and quick experiments, not as a novel architecture or a model of any specific chip.

Device and circuit

Writing the weights into the array

Before any multiply, each weight has to be written as a conductance. The controller first erases the array to the high-resistance state, then nudges each cell with SET pulses (raise G) and RESET pulses (lower G), reading it back after every pulse and stopping when it is within tolerance of its target. The conductances this produces are the ones the crossbar above computes with. The device model is a simple illustrative one, so adjust it to explore the trade-offs.

Trace one output

Each cell current is Vᵢ·Gᵢⱼ (Ohm). The bit line adds them (Kirchhoff). The two bit lines of a pair are subtracted, then scaled by Vread·(Gmax−Gmin) to recover the weighted sum.

Efficiency versus digital multiply-accumulate

A conventional processor fetches every weight from memory and performs the M×N multiply-adds one batch at a time. The crossbar keeps the weights where they are and finishes all of them in a single read. The figures come from an illustrative energy and timing model, so adjust the assumptions to match a design you care about.
